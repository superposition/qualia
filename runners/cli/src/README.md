# `runners/cli/src`

## Purpose
Source for the `qualia` operator binary.

- `main.rs` — entry point
- `cli.rs` — argument grammar, diagnostics and usage text
- `commands.rs` — execution of each parsed command
- `http.rs` — bounded JSON-over-HTTP requests to the agent
- `platform.rs` — host, process and manifest inspection
- `world.rs` — world-model envelopes, wire documents and body summaries
